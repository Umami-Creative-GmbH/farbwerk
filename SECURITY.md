# Security Policy

## Supported Version

Security reports are accepted for the current version of Farbwerk deployed at [farbwerk.umami-creative.de](https://farbwerk.umami-creative.de).

## Reporting a Vulnerability

Please do not report vulnerabilities in public issues, discussions, or pull requests.

Report them privately to [Umami Creative GmbH](https://umami-creative.de). Include `SECURITY` in the subject or opening line and provide:

- a clear description of the issue;
- steps to reproduce it;
- the potential impact; and
- any suggested mitigation, if available.

We will review the report, work on a fix where appropriate, and coordinate public disclosure after affected users have had a reasonable opportunity to update.
